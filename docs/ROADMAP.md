# Roadmap

路线图只表达公开仓库当前可确认的方向，不代表承诺的发布日期。

## 当前阶段：可复现的本地优先 MVP

- 稳定本地素材导入、浏览器主动捕获、分类、标签、搜索和回收站流程。
- 保持后端回归测试、前端构建和开源脱敏检查可重复执行。
- 持续统一普通版公开仓库、Windows 打包资源和文档中的产品品牌。

## 下一阶段候选

- 更完整的 Windows 安装/升级体验与版本发布说明。
- 更强的本地检索，包括可选的向量索引和语义检索实验。
- 浏览器扩展的打包、更新和权限说明完善。
- 在明确授权、预算可控的前提下扩展 AI 丰富能力。

## 明确边界

- 不把项目变成未经用户同意的批量抓取工具。
- 不默认上传原始素材或自动调用收费 AI 服务。
- 不在公开仓库发布真实用户数据、正式数据库、密钥或本机发布目录。
