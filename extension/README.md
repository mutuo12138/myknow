# myknow 浏览器扩展

## 安装

1. 先启动 myknow 本机服务。
2. Chrome 地址栏打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择当前文件夹 `extension/`。

更新扩展代码后，在扩展管理页点击一次“重新加载”。0.4.1 起会自动为已经打开的网页重新注入采集脚本；若某个网页仍没有响应，切换到其他标签再切回来即可触发检查，必要时再刷新该网页一次。

## 使用

扩展默认不会注入 `localhost`、`127.0.0.1`、`0.0.0.0` 和 `::1` 页面。这样在 myknow 本机素材库或其他本机开发页面中拖动图片时，不会弹出采集面板；更新扩展后请在扩展管理页点击“重新加载”，再刷新已经打开的本机页面。

扩展弹窗会显示本机连接状态，并提供“保存当前页面”和“打开素材库”。弹窗和网页投递面板都有“保存到”文件夹选择器。

在网页上：

1. 网页右侧会显示一个固定的“采集”小窗。直接点击上半部分即可一键保存当前网页，不必再打开扩展弹窗；不需要时点击右上角关闭按钮，选择会被记住。
2. 点击小窗下半部分的箭头，可以选择目标文件夹、保存当前网页，或保存鼠标正在指向的图片、视频或链接。
3. 拖动图片、视频或链接时仍会出现就近投递面板；拖到面板中央并松手即可保存。也可以在媒体上长按约 650 毫秒后保存。
4. 关闭后可在扩展弹窗通过“网页悬浮采集窗”开关重新开启。文字、图片、视频、链接仍可使用右键菜单和快捷键保存。

## 快捷键

- `Alt+Shift+I`：先把鼠标停在图片、视频或链接上，再按快捷键保存鼠标下的素材。
- `Alt+Shift+S`：保存当前网页。

快捷键默认保存到扩展弹窗“保存到”所选的文件夹。点击弹窗中的“修改快捷键”，可在 Chrome/Edge 原生快捷键页面重新绑定；若组合键与其他软件冲突，也在这里修改。

扩展只在你主动操作后提交当前页面元数据、选中文字和媒体引用；不批量爬取，不强制下载受保护视频。保存单张图片时，扩展会优先用当前浏览器会话读取该图片并传给本机服务，这能处理部分需要登录或带防盗链的图片；单张图片限制为 8 MB。网页保存时会传送经清理的 HTML 快照给本机服务，供后续生成离线 PDF/Word。
