# myknow 0.1.1

这是 myknow 的 Windows 安装版，包含软件本体和浏览器采集扩展。安装程序会创建开始菜单与桌面快捷方式，并提供正常卸载入口。

## 第一次使用

1. 从桌面或开始菜单启动 `myknow`。
2. 软件会在当前 Windows 用户的“文档”目录建立 `myknow` 数据文件夹；如果发现旧的 `Muse Vault` 数据目录，会优先兼容旧目录。
3. 打开软件里的“网页采集”页面，点击“下载浏览器插件”；安装版会弹出系统保存窗口。
4. 解压下载的 `myknow-extension.zip`，按插件安装说明加载解压后的文件夹。

## 数据、导入与卸载

- 默认素材库位于当前用户“文档”目录下的 `myknow` 文件夹，也可在软件内选择其他磁盘。
- “引用文件夹”模式创建链接，不复制原始大图；删除引用记录不会删除原始图片。
- 素材库和日志不能放入软件安装目录，以免升级或卸载影响用户数据。
- 卸载软件只移除程序文件，不主动删除文档目录中的素材库、日志或 AI 配置。

## 安全与隐私说明

- 安装包不包含开发机的数据库、素材、日志、AI 配置、API Key、Cookie 或测试图片。
- 软件首次启动时会创建一份全新的本地素材库。
- 浏览器插件不会静默安装；Chrome/Edge 要求用户在扩展管理页明确确认“加载已解压的扩展程序”。
- 安装版点击下载会显示实际保存位置；若取消文件对话框，不会误报“已开始下载”。
- AI 默认关闭。只有你在软件里打开并确认配置后，才会产生 AI 请求。

## 退出软件

关闭主窗口后，myknow 会缩入 Windows 通知区域并继续提供浏览器采集服务。需要彻底退出时，请在托盘图标菜单中选择“退出 myknow”。

## 代码签名

当前安装程序尚未购买商业代码签名证书，Windows 可能显示“未知发布者”。请只使用项目正式交付的安装包，并在安装前核对交付报告中的 SHA-256。
