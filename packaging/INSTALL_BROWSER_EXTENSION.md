# 安装 myknow 浏览器插件

Chrome 和 Edge 不允许普通桌面软件静默安装插件，所以需要你手动确认一次。整个过程只需几步：

1. 在 myknow 的“网页采集”页面点击“下载浏览器插件”。安装版会弹出系统保存窗口，请选择保存位置。
2. 解压 `myknow-extension.zip`，得到一个 `myknow-extension` 文件夹。
3. Chrome 地址栏打开 `chrome://extensions`；Edge 地址栏打开 `edge://extensions`。
4. 打开右上角“开发者模式”。
5. 点击“加载已解压的扩展程序”，选择刚才解压出的 `myknow-extension` 文件夹。
6. 看到 myknow Capture 后，刷新已经打开的网页。

说明：Chrome/Edge 不允许普通桌面软件静默安装扩展，因此最后一步必须由你在浏览器扩展管理页明确点击“加载已解压的扩展程序”。myknow 负责把扩展 ZIP 随产品打包并通过系统保存窗口导出，不会绕过浏览器的安全确认。

以后更新插件：

1. 下载并解压新的 ZIP。
2. 在扩展管理页点击 myknow 的“重新加载”。
3. 刷新目标网页。

## 常用操作

- 点击网页右侧采集浮窗：保存当前网页。
- 鼠标停在图片上使用快捷键：保存当前图片。
- `Alt + Shift + I`：保存鼠标悬停的图片或媒体。
- `Alt + Shift + S`：保存当前网页。
- 浮窗右上角可以关闭；以后从插件弹窗恢复。

快捷键可以在 `chrome://extensions/shortcuts` 或 Edge 的扩展快捷键页面重新设置。

## 隐私提醒

插件只在你主动点击、使用右键或快捷键时采集。不要在银行、密码管理器、企业内网或你无权保存的页面上使用采集功能。
